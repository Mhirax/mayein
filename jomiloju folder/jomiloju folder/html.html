Chapter 01

Learn HTML From Scratch

HTML is the language that gives structure to every webpage. Master the fundamentals here.

LESSON 01

What is HTML?

HTML stands for HyperText Markup Language. It's not a programming language — it's a markup language that tells your browser how to structure the content on a page. Think of HTML as the skeleton of a website.

<h1>Hello World</h1> <p>This is a paragraph.</p>

Hello World

This is a paragraph.

Every HTML document starts with <!DOCTYPE html> to tell the browser which version of HTML you're using.
Create a file called index.html and write your first HTML document with a heading and a paragraph.
LESSON 02

HTML Document Structure

Every HTML page follows the same basic structure. The <html> tag wraps everything, <head> contains metadata, and <body> contains what you see.

<!DOCTYPE html> <html lang="en"> <head> <title>My Page</title> </head> <body> <h1>Welcome</h1> </body> </html>
The lang="en" attribute helps search engines and screen readers understand your content's language.
LESSON 03

Headings

HTML headings are used to create titles and subtitles on a webpage. There are six levels, from <h1> (most important) to <h6> (least important).

<h1>Main Title</h1> <h2>Subtitle</h2> <h3>Section Title</h3>

Main Title

Subtitle

Section Title

Use only one <h1> per page — it represents the main topic.
Write a page about your favorite hobby using at least three heading levels.
LESSON 04

Paragraphs & Text

Paragraphs are created with the <p> tag. You can also use <strong> for bold and <em> for italic text.

<p>This is a paragraph.</p> <p>This has <strong>bold</strong> and <em>italic</em> text.</p>

This is a paragraph.

This has bold and italic text.

LESSON 05

Links & Images

Links use the <a> tag with an href attribute. Images use the self-closing <img> tag with src and alt attributes.

<a href="https://example.com">Click me</a> <img src="photo.jpg" alt="A sunset" />
Always include alt text on images — it's essential for accessibility.
LESSON 06

Lists

HTML supports ordered lists (<ol>) and unordered lists (<ul>). Each item is wrapped in <li>.

<ul> <li>Apples</li> <li>Bananas</li> </ul>
  • Apples
  • Bananas
LESSON 07

Semantic HTML

Semantic tags describe their meaning: <header>, <nav>, <main>, <article>, <section>, <footer>. They make your code more readable and accessible.

<header>...</header> <nav>...</nav> <main> <article>...</article> </main> <footer>...</footer>
Use semantic tags instead of generic <div> whenever possible.
