Chapter 02

Learn CSS From Scratch

CSS brings your HTML to life with colors, layout, typography, and beautiful design.

LESSON 01

What is CSS?

CSS (Cascading Style Sheets) controls how HTML elements look. It handles colors, fonts, spacing, layout, and animations. Without CSS, every website would look like a plain text document.

h1 { color: #6366f1; font-size: 32px; }
CSS stands for "Cascading" because styles can cascade and override each other based on specificity.
LESSON 02

How to Add CSS

There are three ways to add CSS: inline (on the element), internal (in a <style> tag), or external (in a separate .css file). External is the best practice.

/* External CSS file */ <link rel="stylesheet" href="style.css" />
LESSON 03

Selectors

Selectors target HTML elements. Use element names, classes (.), or IDs (#).

p { color: black; } /* element */ .card { padding: 20px; } /* class */ #header { background: blue; } /* id */
Prefer classes over IDs for styling — they're reusable and have lower specificity.
LESSON 04

Colors

CSS supports many color formats: named colors, HEX, RGB, RGBA, and HSL.

.box { color: red; background: #6366f1; border: 1px solid rgb(0, 0, 0); }
LESSON 05

Box Model

Every element is a box with four layers: content, padding, border, and margin.

.box { width: 200px; padding: 20px; border: 2px solid black; margin: 10px; }
Add box-sizing: border-box to make width include padding and border.
LESSON 06

Flexbox

Flexbox is a one-dimensional layout system. Perfect for aligning items in a row or column.

.container { display: flex; justify-content: center; align-items: center; gap: 16px; }
LESSON 07

CSS Grid

Grid is a two-dimensional layout system. Perfect for complex page layouts with rows and columns.

.grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }
LESSON 08

Responsive Design

Media queries let you apply different styles based on screen size. Mobile-first is the modern approach.

.grid { grid-template-columns: 1fr; } @media (min-width: 768px) { .grid { grid-template-columns: repeat(2, 1fr); } }
Build a card layout that's one column on mobile, two on tablet, three on desktop.
