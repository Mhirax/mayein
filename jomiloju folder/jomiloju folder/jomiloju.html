The Basics

What is a static website?

A static website is a collection of HTML and CSS files sent directly to your browser. No databases, no servers running complex code — just files that describe structure and style. Every website you visit starts with these two languages.

</>

HTML = Structure

HTML defines the content and structure of your page — headings, paragraphs, images, links, and more.

{ }

CSS = Style

CSS controls how everything looks — colors, fonts, spacing, layout, and responsive behavior.

◎

Browser = Result

Your browser reads the HTML and CSS files and renders the final website you see on screen.

Step 01

Learn HTML

HTML (HyperText Markup Language) creates the structure of every website. It uses tags to define headings, paragraphs, images, links, lists, and more. Think of it as the skeleton of your page.

Every HTML document follows a simple pattern: you open a tag, add content, and close the tag. That's it.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Site</title>
  </head>
  <body>
    <h1>Hello, World</h1>
    <p>Welcome to my
       first website.</p>
  </body>
</html>

Step 06

Responsive design

A responsive website adapts to any screen size — desktop, tablet, or mobile. Using CSS media queries, you can change layouts, font sizes, and spacing based on the viewport width.

This isn't optional. Over 60% of web traffic comes from mobile devices. Every website you build must work everywhere.

style.css 
/* Mobile first */
.grid {
  grid-template-columns: 1fr;
}

/* Tablet */
@media (min-width: 768px) {
  .grid {
    grid-template-columns:
      repeat(2, 1fr);
  }
}

/* Desktop */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns:
      repeat(3, 1fr);
  }
}

Our Philosophy

You don't need a framework to build something great.

The modern web is obsessed with tools, libraries, and frameworks. But every framework is built on top of HTML and CSS. When you learn the foundations, you understand how everything works — and you can build anything, with or without a framework.

Start simple. Learn the languages of the web. Build real things. The frameworks can wait.
